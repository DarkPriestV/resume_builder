# AI Resume Builder

An AI-powered Resume Builder that helps users create professional resumes quickly using customizable templates and AI-assisted content generation.

## 🚀 Features

- Create professional resumes instantly
- AI-generated resume summaries and bullet points
- Multiple resume templates
- Export resumes as PDF
- Easy customization
- Responsive UI
- Save and edit resumes

## 🛠 Tech Stack

- Frontend: React / Next.js
- Backend: Node.js / Python
- Database: MongoDB / PostgreSQL
- AI Integration: OpenAI API
- Styling: Tailwind CSS
